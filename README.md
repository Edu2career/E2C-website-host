# Edu2Career

This repo contains the public Edu2Career website.

Live site: https://edu2career.me

The site is hosted with GitHub Pages and published from the `main` branch.

## Run it locally

From the repo folder, run:

    python3 -m http.server 8000

Then open:

    http://localhost:8000

## Deployment

GitHub Pages publishes the site from the `main` branch.

The `CNAME` file connects GitHub Pages to `edu2career.me`.
